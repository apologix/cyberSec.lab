# Reconocimiento

Directorio para imágenes y definiciones reproducibles de Nmap, Nuclei y herramientas de reconocimiento.

Nuclei está implementado en `nuclei/` con bridge dedicado, policy routing y kill switch. Nmap conserva el flujo reproducible existente con ProtonWG para objetivos externos.

La explicación completa de Nuclei está en [`nuclei/README.md`](nuclei/README.md). Incluye instalación, plantillas, tipos de comprobación, comandos, resultados, Interactsh, límites y flujo con Nmap.
