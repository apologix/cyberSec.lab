# Have I Been Pwned

Proveedor API para metadatos legítimos de exposición de un correo: brechas y
clases de datos afectadas. No se descargan ni reconstruyen contraseñas. Requiere
`HIBP_API_KEY` local cuando el endpoint lo exija y conserva referencias en
`CASE/raw/osint/hibp/`. Se accede desde `osint-runner` en `vpn`.
