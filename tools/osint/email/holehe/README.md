# Holehe

Consulta indicadores públicos de posible registro de una dirección de correo en
servicios. Una respuesta `exists` no confirma que una persona controle la
cuenta. Se ejecuta desde `osint-runner` en `vpn`, con salida en
`CASE/raw/osint/holehe/`. Actualice revisando la dependencia y valide con una
dirección de prueba propia. No fuerce límites ni cambie de IP para evadirlos.
