# Sherlock

Maigret como segunda fuente independiente: Sherlock es más directo; Maigret
aporta más metadatos y formatos de informe. Ambos resultados son indicadores.
Ejecución: `osint-runner`, modo `vpn`, salida en `CASE/raw/osint/sherlock/`.
