# Maigret

Investiga presencia de usernames y puede producir reportes estructurados. Sus
coincidencias pueden contener falsos positivos; conserve JSON/CSV/HTML en
`CASE/raw/osint/maigret/` y correlacione solo con evidencia adicional. Se
ejecuta desde `osint-runner` en `vpn`; la versión inicial declarada es 0.6.5.
