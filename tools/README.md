# Herramientas

Las herramientas se organizan por función:

- `recon/`: reconocimiento y enumeración inicial.
- `osint/`: investigación pública, proveedores y automatización.
- `tls/`: revisión de protocolos, certificados y HTTPS.
- `forensics/`: análisis offline de evidencia y artefactos.
- `vulnerabilities/`: evaluación de vulnerabilidades.
- `windows/`: SMB, Active Directory y protocolos relacionados.
- `web/`: proxies y pruebas de aplicaciones web.
- `network/`: generación, inspección y manipulación de paquetes.
- `visibility/`: captura y análisis de tráfico de la red local.
- `validation/`: validación controlada, incluyendo Metasploit.

Cada herramienta tiene una guía de instalación, un modo de red permitido y una prueba de verificación.
