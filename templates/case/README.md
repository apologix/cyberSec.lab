# Plantilla de caso

Esta plantilla es la unidad operacional del laboratorio. Los casos reales se
crean fuera de Git con `scripts/new-case.sh`; no copie evidencia, credenciales
ni objetivos al repositorio.

`raw/` conserva salidas originales. `evidence/` contiene solo artefactos
seleccionados y referenciados. Una coincidencia OSINT es un indicador, no una
confirmación de identidad.
